The project

About li4chess

li4chess is a free, ad-free, open-source way to play four-player chess in your browser. An independent project, made for local games and computer opponents.

The name and visual style take inspiration from Lichess. li4chess is independently maintained and is not affiliated with or endorsed by Lichess or Chess.com. Its four-player free-for-all rules follow the project's documented standard FFA contract.

Play four-player chess

What you can play here

Play Red against three computers, mix human and CPU seats, or share one device with friends. Computers run in your browser with ten difficulty levels. The game has no running clocks, and you do not need an account, subscription or installation.

Legal-move highlights, keyboard controls, optional owner letters and board rotation help you follow four armies. You can resize the board, use Zen mode, resume a browser-local save or export a replay to keep it.

The public site offers local and CPU play. Online friend-invite rooms, matchmaking, persistent accounts and ratings are not available here. Development work preserved in the repository does not imply an upcoming public service or a promised feature schedule.

New to this format? Read the rules and scoring guide, then try the beginner strategy guide.

Feedback and bug reports

Use li4chess GitHub Issues to report a bug, ask a question about the game or suggest a focused improvement. Reading existing reports is public; creating a report requires a GitHub account.

A useful bug report includes:

  • What you expected, what happened, and the steps that reproduce it.
  • Your browser and device, plus a screenshot if it explains the problem.
  • A replay exported from More game tools, when the issue concerns a game position.

Reports and attachments are public. Remove personal information before sharing them. Feedback is welcome, but there is no guaranteed response time or delivery commitment.

Source, licensing and credits

The application source is available in the li4chess GitHub repository under GNU AGPL version 3 only. The repository includes setup instructions, the rules specification, tests and project decisions.

The chess piece artwork is by Colin M. L. Burnett, reused under GPL version 2 or later from the Lichess source repository. li4chess adapts its colors for the four armies. The learning diagrams use the same credited shapes on original li4chess board layouts.

Browser CPU play uses the MIT-licensed Tetrarch v8 adviser by IchNukeDichWeg, with li4chess validating moves and determining rules and results. CPU levels describe resource budgets; no measured rating or playing-strength guarantee is claimed.

See the complete third-party notices for retained licenses, upstream sources and runtime credits, including Emscripten.

Local games and website analytics

Your game and display preferences are saved in this browser when storage is available. The public website also uses Google Analytics 4 and Microsoft Clarity through Cloudflare Zaraz to understand visits and usability. Clarity can collect visible interactions for session replay.

Read Privacy on li4chess for the distinction between local game files, website analytics and hosting, along with provider information and browser controls.
