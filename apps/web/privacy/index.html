Privacy on li4chess

The game runs on your device. The public website also uses analytics to understand visits and how the interface is used.

Last reviewed November 8, 2026. This explanation covers the public local/CPU site at li4chess.org.

At a glance: no li4chess account is needed. Game saves stay in this browser. Google Analytics 4 and Microsoft Clarity are configured through Cloudflare Zaraz; Clarity can collect page interactions for heatmaps and session replays.

Games, preferences and replay files

li4chess uses browser storage to keep one saved game and display choices such as board size, Zen mode and owner letters. Saves include the game position, seat choices and move history. They are specific to this browser and device and do not sync to a cloud-save account.

Starting a new game replaces the saved game. Clearing this site's browser data can remove the save and preferences. Private browsing or blocked storage can prevent a save from persisting.

Importing a replay reads the file in your browser. Exporting creates a file for you to download. There is no automatic replay-upload feature. If you attach a replay or screenshot to a GitHub report, it becomes public with that report.

Browser-local storage is separate from analytics. Information displayed on the page and your interactions with the board or controls may be visible to the analytics services described below.

Google Analytics 4 and Microsoft Clarity

These services are configured at the Cloudflare edge using Zaraz. Cloudflare can add the analytics integration while delivering the site, even though the application's source HTML contains no analytics tag.

Google Analytics 4: visits and usage

GA4 helps the project understand page visits and overall site use. Google's documentation describes session statistics, approximate location, and browser and device information among its default data categories. Analytics can use browser identifiers and cookies, depending on the integration and storage settings.

See Google's data collection explanation and Google's Privacy Policy for provider details.

Microsoft Clarity: interface interactions

Clarity helps identify confusing controls and usability problems through behavioral metrics, heatmaps and session replay. It can collect clicks or taps, scrolling, mouse movement, page structure and displayed content, along with technical and diagnostic information. A session replay reconstructs visible website interactions; it is separate from an exported li4chess chess replay.

Clarity uses cookies and other tracking technologies, with collection depending on service settings, browser behavior and applicable consent signals. Microsoft processes this information under its own policies; its disclosure also describes uses for site optimization, security and advertising.

See Clarity's data collection documentation, Microsoft's Clarity disclosure and the Microsoft Privacy Statement.

Hosting and other services

The website's files are hosted on GitHub Pages and delivered through Cloudflare. Requests pass through these providers to load the site. They may process technical request data such as your IP address, requested URL and browser information to deliver, operate and protect their services.

Cloudflare also supplies Zaraz for the analytics integrations. Recent deployment checks recorded Cloudflare RUM performance beacons on the public site; performance telemetry is another form of website measurement.

Read GitHub's Privacy Statement, Cloudflare's Privacy Policy and the Zaraz FAQ for more information.

Links to source code, credits and feedback lead to GitHub. Using GitHub to create an issue is subject to its account and privacy terms. The public game itself does not create a li4chess account or offer hosted multiplayer.

Your browser controls

  • Keep a game before clearing data. Export its replay from More game tools, then use your browser's site-data controls to remove local storage and cookies.
  • Manage cookies and tracking. Browser privacy controls or content blockers may limit analytics. Blocking cookies alone may still allow some measurement; it does not guarantee that all collection stops.
  • Read without JavaScript. These information pages and guides remain readable. Playing the game requires JavaScript.
  • Run your own copy. The repository's local setup instructions let you play outside the public domain's Cloudflare analytics injection.

Analytics cookie behavior, retention and consent handling depend on the live service configuration and provider policies. Site-specific retention periods and a universal analytics opt-out are not published here. Consult the linked policies for provider controls and privacy rights.

Questions or corrections

For questions about this explanation, use li4chess GitHub Issues. It is a public channel: keep account details, identifiers and other private information out of your report.
